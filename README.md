# Study & Interview Preparation System

A Java-based application designed to help students organize their studies and prepare for technical interviews and placements.

## Planned Features

- Student dashboard
- Study task management
- Data Structures and Algorithms (DSA) tracker
- Aptitude and technical quizzes
- Preparation progress analytics

## Technology Stack

- Java 21
- Spring Boot
- MongoDB Atlas
- HTML, CSS and JavaScript
- Git and GitHub

## Project Status

Currently in development.

## Goal

To build a practical full-stack application that demonstrates Java programming, backend development, database integration, and problem-solving skills.
